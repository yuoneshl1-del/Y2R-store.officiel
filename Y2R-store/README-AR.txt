Y2R Store — نسخة تطوير محسّنة

تشغيل محلي:
1. ثبّت Node.js (إصدار 18 أو أحدث).
2. شغّل INSTALL-AND-RUN.bat أو افتح Terminal داخل المجلد ثم نفّذ: npm install ثم npm run dev
3. افتح http://localhost:3000
4. لوحة الطلبات: http://localhost:3000/admin.html — مفتاح الإدارة يظهر في نافذة الخادم. يمكنك تعيينه في .env.

المزايا المضافة:
- صفحة تتبع الطلب برقم الطلب + الهاتف، مع عرض حالة الطلب ومحتوياته.
- حالات الطلب: جديد، تم التأكيد، قيد التحضير، خرج للتوصيل، تم التسليم، ملغى.
- تغيير حالة الطلب من لوحة الإدارة.
- نقطة فحص صحة الخادم /api/health.
- تحقق إضافي من المقاسات والبيانات وتحديد معدل الطلبات.
- تحسينات واجهة، التركيز بلوحة المفاتيح، وحالة تتبع الطلب.

تعديل المنتجات:
- الأسعار والمنتجات في data/products.json.
- الصور في public/images. لا تضف صورة لا تملك حقوق استخدامها.

مهم قبل إطلاق تجاري:
هذه النسخة ما زالت DEMO: الطلبات محفوظة بملف JSON وليست قاعدة بيانات إنتاجية، ولا يوجد دفع إلكتروني أو تكامل شركة توصيل.
- لا تجمع بيانات زبائن حقيقية على النسخة التجريبية.
- عند النشر، أضف ملف .env مع ADMIN_KEY قوي وفريد وNODE_ENV=production.
- راجع سياسة الخصوصية، الشروط، سياسة الإرجاع، بيانات النشاط التجاري، أسعار/مناطق التوصيل، واتفاق شركة التوصيل.
- استخدم قاعدة بيانات موثوقة، نسخ احتياطي، HTTPS، حماية مناسبة للوحة الإدارة، وسجل تدقيق قبل التعامل مع بيانات حقيقية.
- فعّل وسيلة تواصل حقيقية بعد الحصول عليها؛ بيانات الهاتف وواتساب الافتراضية ليست مفعّلة.
- لا تعلن أن الدفع أو التوصيل أو الإرجاع متاح فعليًا إلا بعد الاتفاق والتفعيل.


تطوير إضافي (الدفعة 2):
- قائمة مفضلة تحفظ على جهاز المستخدم عبر LocalStorage.
- زر المفضلة على بطاقات المنتجات، وإمكانية عرض قائمة المفضلة.
- فلتر أقصى سعر لتسهيل اكتشاف المنتجات ضمن الميزانية.
- مركز مساعدة يحتوي أسئلة متكررة بصياغة واضحة، مع تذكير بأن التوصيل والدفع غير مفعّلين.
- لوحة الإدارة تدعم تصدير الطلبات إلى CSV (للاستخدام التجريبي فقط).
- تحسينات responsive وحركات ووضوح الأزرار.


ميزة إلغاء الطلب من العميل (مضافة):
- من قسم تتبع الطلب، يستطيع العميل إلغاء الطلب بنفسه إذا كان جديدًا أو تم تأكيده أو قيد التحضير.
- يتطلب رقم الطلب ورقم الهاتف الذي استعمله العميل عند الشراء للتحقق.
- الإلغاء يتم على الخادم مباشرة، ويظهر في لوحة الإدارة كـ (إلغاء من العميل).
- لوحة الإدارة تتحدث تلقائيًا كل 30 ثانية، وتعرض ملخصات وعدد الطلبات والملغاة، مع بحث وفلترة.
- لا يسمح بالإلغاء بعد خروج الطلب للتوصيل أو تسليمه. الطلب الملغى لا يمكن إعادة فتحه من لوحة الإدارة.
- لا تزال هذه نسخة تجريبية تخزن الطلبات في JSON؛ قبل البيع الحقيقي يجب الانتقال إلى قاعدة بيانات وتفعيل HTTPS وحماية مناسبة.


تحديث لوحة الإدارة: التصدير الشامل Excel-compatible يحتوي ملخصًا وبيانات شهرية وورقة الطلبات وورقة مصاريف قابلة للإدخال. الربح تقديري فقط لأن تكلفة الشراء غير مدخلة افتراضيًا. أرقام الهاتف تطبع بصيغة الجزائر 05/06/07 + 8 أرقام، وتُوحّد صيغة +213 أو 213 إلى صيغة محلية عند الإدخال.
